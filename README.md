# MyBank — OOP

A simple **banking application built with TypeScript** to practice **Object-Oriented Programming (OOP)** concepts.

This project was developed during my time at **PIAIC (Presidential Initiative for Artificial Intelligence and Computing)** as part of my early programming and TypeScript learning.

## About

MyBank is a basic banking system designed to model common banking operations using an object-oriented approach.

The project was primarily created as a practical exercise for understanding how real-world entities and their behavior can be represented using **classes, objects, methods, and encapsulation**.

## Key Concepts

Through this project, I practiced:

* Object-Oriented Programming with TypeScript
* Classes and objects
* Encapsulation
* Constructors and methods
* Modeling real-world entities in code
* Managing application state
* Implementing banking-related operations
* Structuring TypeScript applications

## Tech Stack

* **TypeScript**
* **Node.js**
* **Inquirer**
* **Chalk**
* **Chalk Animation**

## Installation & Usage

### Run with npx

The application is published as an npm package and can be run directly using:

```bash
npx adil-mybank
```

### Run from Source

Clone the repository and install its dependencies:

```bash
git clone https://github.com/SheikhXAdil/myBank-OOP.git
cd myBank-OOP
npm install
```

Then run the application using the project's compiled JavaScript file:

```bash
node index.js
```
